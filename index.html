Game tools, trackers and calculators

BuffForge is a free collection of game tools, trackers and calculators. Every number cites a public source and a review date. There is no login and no advertising. Tools are organized by game: open a game to find its trackers, checkers and (when we have sourced figures) guides. BuffForge is an independent fan project, not affiliated with any publisher. Written guides are added only when we can source the numbers — today the live work is the tools.

The method

How we check every number

  1. Public sources onlyNumbers come from official notes, official or well-sourced wikis, and public APIs. We never invent odds.
  2. Versioned and datedEvery tool shows its data version, sources, and review date. Early-access figures can change.
  3. Tell us when we are wrongIf we get a number wrong, tell us. We correct it.

Questions

Frequently asked questions

What is BuffForge?

A free site of game tools, trackers and calculators. Every number has a source and a review date.

Do I need an account?

No.

Is BuffForge official?

No. BuffForge is an independent fan project, not affiliated with any publisher.

Which games are covered?

See the Games section. We add a game only when we can source the numbers. AION 2 and GTA 6 were the first; Desktop Pension Squad is the newest addition.

How do you check numbers?

Public sources only. Every tool shows its data version, sources, and review date. Corrections are welcome — see About.
