Desktop Pension Squad tools and guides

This is the BuffForge hub for Desktop Pension Squad tools and guides. The live tool is a fuse or salvage calculator: nine-item fusion odds for every level bracket, plus a Soul comparison when you enter sell prices. The odds are transcribed from DPSquad Wiki, which reads them from the game client (v1.0.2, Steam build 26611958, reviewed Nov 12, 2026 Pacific Time). The game is free to play on Steam Early Access. Frequently asked questions

How does fusion work in Desktop Pension Squad?

Fusion combines nine items of the same rarity, category and level bracket into one item of a higher rarity. The result rarity is random; the odds are listed in the calculator. Unequip the items first — equipped items cannot be fused.

Where do the fusion odds come from?

The odds are transcribed from DPSquad Wiki, which reads them from the game client (version 1.0.2, Steam build 26611958). We reviewed the table against the wiki on Nov 12, 2026, Pacific Time. The game is in Early Access, so the numbers can change with patches — the calculator shows its data version.

Is Desktop Pension Squad free?

Yes. It is free to play on Steam (Early Access since Nov 11, 2026). There is no official Russian server; the game has a Russian interface.
